# نرگس جعفر طباطبایی — وب‌سایت شخصی

وب‌سایت پورتفولیوی شخصی، دوزبانه — فارسی (`/fa`، راست‌به‌چپ) و انگلیسی (`/en`) — با پالت «ابسیدین و شامپاینی» و حالت روشن/تیره.

## پشته

| بخش | ابزار |
| --- | --- |
| فریم‌ورک | Next.js 15 (App Router) + TypeScript |
| استایل | Tailwind CSS v4 + کامپوننت‌های shadcn/ui (Dialog، Button) |
| موشن اصلی | GSAP + ScrollTrigger (`@gsap/react`) |
| اسکرول نرم | Lenis (متصل به ticker گسپ) |
| سه‌بعدی | Three.js + React Three Fiber |
| تعاملات کوچک | Motion (`motion/react`) |

## اجرا

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
npm run lint && npm run typecheck
```

## خروجی HTML مستقل

```bash
npm run export:html
```

فایل‌های `html/fa.html`، `html/en.html` و `html/index.html` (= فارسی) ساخته می‌شوند (صفحه‌های جداگانه پروژه‌ها و ارسال مستقیم فرم سفارش سرور لازم دارند؛ در این خروجی پروژه‌ها در پنل خودشان باز می‌شوند و فرم، پیام آماده ایمیل/تلگرام می‌دهد). هر فایل کاملاً مستقل است — استایل، فونت‌ها، اسکریپت‌ها، صحنه سه‌بعدی و همه تصاویر داخل خودش است — پس با دوبار کلیک باز می‌شود یا روی هر هاست ساده‌ای (حتی بدون Node) آپلود می‌شود. دو فایل کنار هم که باشند، دکمه «فا / EN» بینشان جابه‌جا می‌کند.

پنل مدیریت سرور لازم دارد و در این خروجی نیست: محتوا را با `npm run dev` در `/keystatic` ویرایش کنید و دوباره خروجی بگیرید.

## رزومه PDF

```bash
npm run resume:pdf
```

از روی صفحه رزومه سایت، فایل‌های `public/files/narges-jafar-tabatabaei-resume-{fa,en}.pdf` و تصویر پیش‌نمایش آن‌ها را می‌سازد (به Chrome/Chromium نیاز دارد؛ در صورت لزوم `CHROMIUM_PATH` را تنظیم کنید) و خروجی HTML را هم به‌روز می‌کند. می‌توانید به‌جای آن، فایل PDF دلخواه را از پنل مدیریت (پروفایل ← فایل رزومه) آپلود کنید.

## فرم سفارش پروژه

فرم چهارمرحله‌ای بخش «سفارش پروژه» درخواست را به `/api/order` می‌فرستد و از آن‌جا به یکی (یا هر دو) مقصد زیر:

| متغیر محیطی | کاربرد |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` | پیام مستقیم در تلگرام. ربات را با ‎@BotFather بسازید، یک پیام به آن بدهید و `chat.id` را از `https://api.telegram.org/bot<TOKEN>/getUpdates` بردارید. |
| `N8N_WEBHOOK_URL` | آدرس Production یک Webhook در n8n؛ درخواست به‌صورت JSON (همراه متن آماده `text`) ارسال می‌شود. |

اگر هیچ‌کدام تنظیم نشده باشد (یا در خروجی HTML مستقل)، فرم پیام آماده را نشان می‌دهد تا بازدیدکننده با ایمیل، تلگرام یا کپی متن بفرستد — هیچ درخواستی گم نمی‌شود.

## سئو و اشتراک‌گذاری

- `NEXT_PUBLIC_SITE_URL` را روی آدرس نهایی سایت بگذارید (لینک‌های canonical، `sitemap.xml`، `robots.txt` و کارت اشتراک‌گذاری از آن ساخته می‌شوند).
- داده ساختاریافته Schema.org (Person + WebSite) در صفحه اصلی.
- کارت‌های اشتراک‌گذاری `public/og/{fa,en}.png` با `npm run og:image` از روی نام، نقش و پرتره ساخته می‌شوند.
- آمار بازدید: Vercel Web Analytics در بیلدهای Vercel فعال است؛ کافی است در داشبورد Vercel ← Analytics روشنش کنید.

## ساختار

```
keystatic.config.ts    ساختار پنل مدیریت (فیلدها با برچسب فارسی)
content/               محتوای قابل ویرایش (YAML): projects/، certificates/، profile.yaml
public/images/         تصاویر پروژه‌ها و مدرک‌ها
src/
  app/[lang]/          layout ریشه به ازای هر زبان (lang/dir)، فونت‌های محلی
  app/globals.css      توکن‌های رنگ دو تم و کلاس .chapter برای بخش‌های تیره
  components/
    sections/          هدر، هیرو، نوار حوزه‌ها، درباره، آمار و کارفرمایان، فرایند، خدمات،
                       ویترین سه‌بعدی، نمونه‌کارها، آموزش، رزومه، سفارش، پرسش‌ها، ارتباط
    case-study.tsx     صفحه کامل هر پروژه (/fa/work/<id>)
    three/dot-field    میدان نقطه‌ای WebGL هیرو (واکنش به نشانگر)
    three/showcase-…   میز لمسی کودک، نمایشگر ۶۵ اینچ و کیوسک سه‌بعدی (R3F)
    motion/            Split، Magnetic، Tilt (کارت‌های خدمات) و Scramble (منو)
    ui/                کامپوننت‌های shadcn/ui
  content/             خواندن محتوای پنل (Keystatic reader)، ابعاد و blur تصاویر، Provider
  app/keystatic        پنل مدیریت؛ app/api/keystatic مسیر API آن
  i18n/                تنظیم زبان‌ها، دیکشنری رابط و Provider
  hooks/               useSectionMotion (واژگان مشترک انیمیشن)، useReducedMotion
```

مسیر `/` به `/fa` هدایت می‌شود.

## پنل مدیریت (`/keystatic`)

همه محتوای سایت از پنل مدیریت قابل ویرایش است — بدون دیتابیس؛ محتوا در پوشه `content/` (YAML) و تصاویر در `public/images/` ذخیره می‌شوند.

| بخش پنل | چه چیزی را تغییر می‌دهد |
| --- | --- |
| **پروژه‌ها** | افزودن/حذف/ویرایش پروژه، آپلود و جابه‌جایی تصاویر، متن فارسی و انگلیسی، لینک، گروه فیلتر، ترتیب نمایش |
| **مدرک‌ها و دوره‌ها** | آپلود مدرک جدید، تصویر، ساعت آموزش (در جمع ساعت‌ها حساب می‌شود)، توضیحات دوزبانه، برچسب‌ها و مهارت‌ها |
| **پرسش‌ها، نظرها و کارفرمایان** | پرسش‌های متداول، نظر کارفرمایان (تا خالی است نمایش داده نمی‌شود)، فهرست کارفرمایان |
| **پروفایل و متن‌های اصلی** | ایمیل، نشان «آماده همکاری»، متن معرفی، پاراگراف‌های درباره، کارت‌های اصول کاری، حوزه‌های کاری |

**روی کامپیوتر خودتان:** `npm run dev` و سپس `http://localhost:3000/keystatic`. تغییرات مستقیم در فایل‌ها ذخیره می‌شوند؛ بعد commit و push کنید.

**روی سایت منتشرشده (مثلاً Vercel):** پنل تغییرات را مستقیم در GitHub commit می‌کند و سایت خودکار دوباره ساخته می‌شود.
1. در تنظیمات هاست متغیر `NEXT_PUBLIC_KEYSTATIC_STORAGE=github` را اضافه و دوباره deploy کنید.
2. به `https://<دامنه>/keystatic` بروید و دکمه ساخت GitHub App را بزنید؛ Keystatic مقادیر `KEYSTATIC_*` را می‌دهد (نمونه در `.env.example`).
3. آن مقادیر را در متغیرهای محیطی هاست بگذارید و دوباره deploy کنید.
4. از این به بعد ورود به پنل با حساب GitHub است — فقط کسانی که به مخزن دسترسی نوشتن دارند می‌توانند ویرایش کنید.

متن‌های ثابت رابط (منو، دکمه‌ها، عنوان بخش‌ها) در `src/i18n/dictionary.ts` هستند.

## جزئیات

- **رنگ:** تم تیره (پیش‌فرض) ابسیدین `#0b0b0c` + استخوانی `#ede8df` + شامپاینی `#d8bb8a`؛ تم روشن کاغذی `#f3efe8` + برنز `#8c6635`. انتخاب کاربر در localStorage می‌ماند.
- **تایپوگرافی:** فارسی Vazirmatn + Markazi Text؛ انگلیسی Geist + Instrument Serif.

- **میدان نقطه‌ای هیرو:** شیدر سفارشی؛ زیر نشانگر فرورفتگی ایجاد می‌کند (اشاره به نمایشگرهای لمسی پروژه‌ها). روی لمسی/در حالت بیکار مسیر آرام هشتی را دنبال می‌کند و فقط وقتی دیده می‌شود رندر می‌شود.
- **نمونه‌کارها:** فهرست ادیتوریال با پیش‌نمایش تصویری که دنبال نشانگر می‌آید، فیلتر با Motion و پنل جزئیات (shadcn Dialog) با لینک مستقیم `#project-<id>`.
- **فرایند:** خط «از ایده تا محصول» با اسکرول کشیده می‌شود و هر مرحله را روشن می‌کند (متن مراحل در پنل ← خدمات).
- **ویترین سه‌بعدی:** محصولات روی سخت‌افزار خودشان؛ با اسکرول از میز کودک (با لانچر زنده) به نمایشگر و کیوسک می‌رود و با کشیدن می‌چرخد (پنل ← خدمات ← ویترین).
- **صفحه هر پروژه:** مسئله، فرایند و نتیجه (اگر در پنل خالی باشند، از معرفی/خدمات/ارزش پروژه پر می‌شوند)، ویدئو، گالری و پروژه بعدی؛ تصویر کاور بین پنل پروژه و صفحه کامل با View Transitions جابه‌جا می‌شود.
- **ویدئو پروژه:** از پنل ← پروژه ← ویدئو (mp4/webm) آپلود کنید؛ خودکار و بی‌صدا پخش می‌شود.
- **آموزش:** شمارنده‌ها و اسکرول افقیِ پین‌شده در دسکتاپ؛ نمایش تمام‌صفحه گواهینامه.
- **دسترس‌پذیری:** `prefers-reduced-motion` همه انیمیشن‌ها و Lenis را خاموش می‌کند؛ بدون جاوااسکریپت هم محتوا دیده می‌شود؛ ناوبری با کیبورد و تمرکز قابل‌مشاهده.
